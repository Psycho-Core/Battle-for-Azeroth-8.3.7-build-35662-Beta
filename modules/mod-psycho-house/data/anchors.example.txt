# Housing.Anchor.File - plot positions for a borrowed map.
#
# One line per plot:   index  x  y  z  o
#
#   index   plot index, 0..54 (the module's kPlotCount)
#   x, y, z world coordinates on Housing.Map.Id
#   o       facing in radians; 0 faces north, and the piece or lot that stands there
#           takes its own orientation from this
#
# `#` starts a comment and blank lines are ignored. A plot index that is not listed keeps
# the computed ring position, so this file can be filled in a few plots at a time: a plot
# left out is a plot still on the ring, not a hole in the neighbourhood.
#
# This file is an example of the format, not a layout to ship. The coordinates are a
# synthetic valley - 12 plots on two rows - chosen so the file can be checked by reading it,
# and every one of them is somewhere an operator has to replace with a surveyed position.
#
# Point the server at a copy of this file with:
#     Housing.Anchor.File = "anchors_founders_point.txt"
# The path is read by the worldserver process, so it is relative to where that process runs.
